# 📅 Randevu Sistemi

Bu proje, Node.js ve React.js kullanılarak geliştirilmiş bir randevu sistemi uygulamasıdır. Kullanıcılar, uygun zaman dilimlerini seçerek randevu oluşturabilirler.

## 🛠️ Teknolojiler

- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Veritabanı:** MongoDB (varsayım)
- **Diğer:** Axios, dotenv

## 🚀 Kurulum ve Çalıştırma

### Backend

1. Projeyi klonlayın:
```
git clone https://github.com/EfsaTortukk/randevu-sistemi.git
cd randevu-sistemi
```

2. Gerekli paketleri yükleyin:
```
npm install
```

3. `.env` dosyasını oluşturun ve gerekli ortam değişkenlerini ekleyin.

4. Sunucuyu başlatın:
```
node server.js
```

### Frontend

1. Frontend klasörüne gidin:
```
cd rezervasyon-frontend
```

2. Gerekli paketleri yükleyin:
```
npm install
```

3. Uygulamayı başlatın:
```
npm start
```
